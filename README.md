# AIForge

AIForge helps you discover, compare, and build with the right AI tools.

## Run locally

    npm install
    PORT=5173 BASE_PATH=/ npm run dev

Open http://localhost:5173.

## Included

- Build advisor with local recommendations
- Searchable tool directory
- Tool details and official links
- Compare workspace
- Stack builder and templates
- Saved tools via localStorage
- Prompt library and field notes
- Responsive desktop and mobile UI
